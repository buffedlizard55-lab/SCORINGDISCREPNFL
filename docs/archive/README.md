# Preserved concurrent draft — NOT the verified dataset or active collector

These files came from main commit `30f402c` during PR #3 conflict reconciliation.
They are preserved as research leads and implementation history, not endorsed as
verified facts or an operational alert service. The active database is
`data/events.json`, active site is generated by `scripts/build.py`, and active
research/limits are in `docs/RESEARCH.md`.

Known concerns: some entries depend only on Reddit; event dates and point-delta
semantics need validation. The old scraper conflates unavailable/empty feeds,
uses guessed table columns, and `--notify` does not deliver a notification.
Do not run it as an official correction service. Old documents' claims of
completeness/live capability are superseded by the current README.

Before admitting any extra case, fetch its sources, match official records,
verify date/teams, establish original and corrected values, and record market
impact separately from actual settlement. Existing overlapping cases should
be reconciled rather than duplicated.
